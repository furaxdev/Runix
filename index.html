Language models that run on your own computer.

Runyx downloads, runs and serves open models locally. One program, a calm chat app, APIs that speak Ollama and OpenAI, and an Android app for the same machine. Open source, no account, no telemetry.

Get started View on GitHub

Pick a model from a list, not a file name.

The Models page is a curated catalog. Each entry says what the model is good at, how big it is, and whether your machine can run it. Download, pause and resume from the same screen. Hugging Face GGUF search is built in.

  • Fits your hardware. Runyx reads your RAM and GPU and marks each model as runs well, runs, or too heavy.
  • Resumable downloads. Interrupted pulls continue where they stopped and are checked with a hash.
  • Already use Ollama? Import your local models and keep your existing tools: Runyx answers on both the Ollama and the OpenAI API shapes.

Bring any file. Any model can read it.

Attachments are turned into text before they reach the model, so a small model with no special skills can still work with your documents.

  • Documents. PDF, Word, Excel, PowerPoint, plain text, code and archives.
  • Images for every model. Models without vision get the text found in the image through OCR. Models with vision see the image itself.
  • Your own knowledge base. Projects with their own instructions, local search over your documents with citations, and a memory you can read and delete.

Private by default.

Everything runs on your machine. Nothing is sent anywhere unless you turn on a feature that needs the network, like web search.

  • Local only. The server listens on your own computer. Other devices need a pairing token that you can revoke.
  • No telemetry. No analytics, no tracking, no account.
  • You approve commands. The shell agent asks before it runs anything, stays inside the folder you choose, and keeps a log.
  • Untrusted by design. Text from files, web pages and images is treated as data, not as instructions.

Your phone, your computer.

Pair an Android phone with a QR code and chat with the models running on your PC, by text or by voice. The model stays at home; the phone is just a window.

  • Pair once. Scan the code shown in the web app. Revoke the phone any time.
  • Share to Runyx. Send text and files from other apps straight into a chat.
  • A full terminal interface. A keyboard and mouse driven screen for the terminal, with selection, markdown styling and copyable commands. In active development.
In development

Runyx Code, a coding agent that stays on your machine.

Open a project or connect a GitHub repository, choose a coding model, and describe the task. Runyx Code reads and edits files, runs commands, takes screenshots and works with branches and pull requests. Every write, command and push waits for your approval, and you can watch and approve from your phone.

Download Runyx 0.1.0

No Go, no build. Unpack the archive, run ./runyx serve, and open 127.0.0.1:11535. The first launch downloads its own inference backend.

Build it, pull a model, start talking.

Build the program. You need Go; Runyx is a single program.

Once the server is running, the web app and both APIs are available on 127.0.0.1:11535. The first run downloads the model engine for your machine.

# build
git clone https://github.com/furaxdev/Runyx
cd Runyx
go build -o runyx ./cmd/runyx# check your machine and see which models fit
./runyx doctor
./runyx recommend# download a model
./runyx pull bartowski/Llama-3.2-1B-Instruct-GGUF# chat in the terminal
./runyx run bartowski/Llama-3.2-1B-Instruct-GGUF# or start the web app and the APIs, same call shape as OpenAI
./runyx serve
curl http://127.0.0.1:11535/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"bartowski/Llama-3.2-1B-Instruct-GGUF",
       "messages":[{"role":"user","content":"Hello"}]}'
